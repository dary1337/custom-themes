# How to install `GitHub` version ?

- Download [zip](https://github.com/dary1337/custom-themes/releases/latest)
- Unpack
- Go to `chrome://extensions/` tab
- Enable developer mode
- Click "Load unpacked"
- Choose unpacked folder
- Enable extension in incognito (if needed)
- Done

# How to update `GitHub` version ?

- If an update is available, you will see "Update extension" button
- Download [zip](https://github.com/dary1337/custom-themes/releases/latest)
- Unpack and replace files in your extension folder
- Reload the extension

# Build from source

extension is `vue 3 + ts`, bundled with `vite` + `@crxjs`

- `npm install`
- `npm run dev` — live dev build with hot reload, load `dist/` as unpacked
- `npm run build` — production build into `dist/` (load that as unpacked)
- `npm run test` — unit tests (vitest)
- `npm run lint` / `npm run typecheck`

`repos.json` stays at the repo root (it's the published theme index, fetched by every install) and gets copied into the build automatically
